# PWA Camera 📷

Una aplicación web progresiva (PWA) de cámara construida con HTML, CSS y JavaScript puro.

## Características

- 📷 Acceso a la cámara del dispositivo (frontal y trasera)
- 🖼️ Galería de fotos tomadas
- ⬇️ Descarga de fotos en formato JPG
- 📱 Instalable como PWA (añadir a pantalla de inicio)
- 🔌 Funciona sin conexión gracias al Service Worker

## Despliegue

La app se despliega automáticamente en **GitHub Pages** al hacer push a `main`.

Para activar GitHub Pages:
1. Ve a **Settings → Pages** en tu repositorio
2. En **Source**, elige **GitHub Actions**
3. Haz push a `main` y la acción se encargará del resto
